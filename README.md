# FinanceManager – Personal Finance Tracker for iOS

FinanceManager is an iOS application for tracking personal and family expenses.  
It helps users record transactions, organize them into categories, and analyze spending through clear statistics and visualizations.

## Features
- Add and manage income and expenses
- Categories for better organization
- Automatic location detection when adding records
- Monthly spending overview
- Pie chart statistics by category
- Receipt scanning using OCR
- Local data persistence with Core Data

## How it works
1. The user adds a transaction manually or scans a receipt.
2. OCR extracts information from the receipt.
3. The current location can be attached automatically.
4. Data is stored locally.
5. Statistics and charts provide spending insights.

## Tech stack
- Swift
- SwiftUI
- Core Data
- Charts
- Location services
- OCR (text recognition)
- XCTest (unit/UI testing)

## Purpose
This project was created as an academic exercise to practice iOS development, local persistence, data visualization, and real-world mobile app features.
