# iOS & watchOS exam prepare

it is an iOS application designed to record and manage study-related entries during exam preparation.  
The app allows users to quickly add records, attach locations, and track their activity across both iPhone and Apple Watch.
The project focuses on practicing native iOS development with Core Data persistence, map-based location selection, current GPS positioning, custom UI design. Each entry can be created with a selected place using a map picker or the device’s current location. Newly added records are immediately synchronized with the Apple Watch for quick access on the go.
The application emphasizes clean architecture, responsive UI, and real-world features such as cross-device communication and local data storage.
